# =============================================================================
#  THE SHADOWED SET
#  Every function that tests/fakes/*.cpp DEFINES and that Pebblebol/src also
#  defines. Whenever a host binary links one of those fakes it drives the FAKE's
#  body while the reader believes it is driving the firmware's.
#
#  WHY THIS FILE EXISTS. Two of the defects this product shipped were exactly
#  that, and neither was visible to any instrument:
#
#    P10-C6  tests/fakes/link_fake.cpp carried a PRE-P10-C4 copy of
#            ui_pet_name_latin1(), so every discovery test drove a function the
#            firmware no longer had - and a device whose owner typed an accented
#            name emitted NO BEACON AT ALL. LINK, trade and P2P battle dead,
#            silently, in a Spanish product.
#    P7      tests/test_trade.cpp bound save_set_clock(nullptr, ...), switching
#            off a whole branch of save_manager.cpp - so a 15-point power-cut
#            sweep ran against a save manager the release artefact does not
#            execute, while on the shipping build EVERY CLEAN TRADE DESTROYED A
#            PEBBLE.
#
#  THE LINKER CAN NEVER CATCH THIS CLASS, and that is measured rather than
#  assumed: intersecting the T/t symbols the six fake objects DEFINE against
#  those the other host objects define finds ZERO, because all fifty shipping
#  bodies live in translation units no host binary compiles. So no object ever
#  defines them and there is never a collision to trip over. Any detector has to
#  be source-based, which is what tools/check.sh section 10 is.
#
#  WHAT THE GATE ENFORCES, per row:
#
#    LINKED     The real body is in a host binary and the fake body is GONE.
#               The gate requires the fake NOT to define the symbol. Drift is
#               impossible by construction; this is the status every row should
#               eventually reach.
#    IMITATION  The fake claims to behave like the shipping body. The gate
#               requires a named ANCHOR - a test case or a check.sh gate - that
#               actually pins the behaviour, and requires that anchor to exist.
#               A row that claims imitation and names nothing is refused.
#    INJECTOR   The fake is DELIBERATELY not an imitation: it is a fault
#               injector or a simulator, and a test that treats it as evidence
#               about the device is misreading it. The gate requires a reason.
#    RECORDER   The fake records a device property instead of reproducing it
#               (a counter a test asserts on). The gate requires a reason.
#
#  AND, ABOVE ALL, THE GATE RE-DERIVES THIS SET FROM SOURCE AND FAILS WHEN IT
#  DIFFERS FROM THIS FILE. A fifty-first shadow cannot appear without somebody
#  writing down which of the four it is, and one cannot silently vanish either.
#  That is the half the P10-C6 exit could not do: it added ONE gate for ONE
#  symbol, after that symbol had already burned somebody.
#
#  WHAT IT DOES NOT CATCH, said plainly so nobody over-reads it:
#    - The P7 shape. A FIXTURE nulling out a shipping seam is not a shadow;
#      tools/check.sh has a separate gate for save_set_clock(nullptr, ...).
#    - Drift ONE CALL DEEP. ui_pet_name_latin1()'s whole body is
#      `{ pet_name_stored(out, cap); }`, so an edit to pet_name_stored() changes
#      no shadowed body. That is why the IMITATION anchors are BEHAVIOURAL
#      (a running assertion) rather than a hash of the text.
#    - The twelve .cpp files with NO fake at all. app/app.cpp holds
#      boot_absence(), which decides whether a power cut costs the player hours,
#      and nothing here covers it.
#
#  FORMAT: symbol  shipping-file  fake-file  STATUS  anchor-or-reason
#  (whitespace separated; the anchor/reason is the rest of the line)
# =============================================================================

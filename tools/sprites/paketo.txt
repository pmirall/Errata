# PAKETO - species 1, family 1 stage 0, type SIGNAL (PACKET / BALANCED).
# 'It hands out letters and never stops.'
# root:       capsule - rounded rect with a solid header stripe
# silhouette: 14x8 capsule, one solid 2px header stripe, two dot eyes on the
#             left cap, four 2px stub feet.
# frame 2:    the capsule tilts 1px nose-up and the stub feet alternate.
# Family motif: a rounded-rect body cut by an unlit HEADER SEAM, eye holes in the header field, stub feet. All three stages are the same rect: whole, torn, then shattered.
# The header stripe is drawn as an UNLIT seam, not a lit one: the body is a
# solid silhouette, so a lit stripe inside it is invisible and an unlit one
# reads as a field divider. The seam is also where the nose-up tilt breaks -
# the 1px step is hidden in a column that is background in both frames.
#
# THE SEAM IS BRIDGED AT ROWS 16-18 (P9-C6) AND THAT IS A FIX, NOT A DECORATION.
# It used to run the FULL height of the body with no bridging row anywhere,
# which split the silhouette into two 8-connected masses of 69 and 63 px - each
# with its own pair of stub feet, so the STARTER, the first creature every
# player meets, read as two small creatures standing side by side rather than as
# one capsule with a field divider. pixio.txt names this exact defect and fixes
# it the same way: "a full-width 1px seam splits the silhouette in two at 1x,
# which is the failure this body already had once." Two hands disagreed about a
# shared rule and the starter was on the losing side. The seam still reads -
# it is unbroken above the bridge and below it - and the body is one piece.
# FRAGMAR and RAFAGON inherit the seam and RAFAGON got the same bridge.
# A blink here is a SQUINT (2x2 hole -> 2x1), never a shut eye: the two frames alternate at even duty, so a fully closed eye reads as flicker.

# Family 14 FILE motif: a SOLID PAGE whose top-right corner is cut away on the
# diagonal, with a 1px unlit CREASE running parallel to that cut, two dot eyes
# and a short mouth low on the page. The crease is stopped one step short at
# both ends so the folded flap stays ATTACHED to the page - a crease that runs
# edge to edge cuts the flap off the silhouette and it reads as a loose bar.
# Growth is by page count: one page, three fanned pages, then a page that has
# unrolled into a burst of page corners big enough to leave the frame.
#
# ARKIVO - species 41, family 14 stage 1, type SYSTEM (FILE / BALANCED).
# 'Guarda mil cosas dentro.' - it keeps a thousand things inside.
# root:       folded-corner sheet (the only folded plane)
# silhouette: three sheets fanned behind one another, each corner folded the
#             other way, bound at the left edge.
# frame 2:    the fan opens one step wider and closes.
# The two sheets behind show only as a 2px band up the right side and three
# rows over the top - that is all a fan of pages IS at this size, and it keeps
# the front page (the face) the biggest single shape. The unlit steps between
# sheets stop short of each sheet's corner so the stack stays ONE connected
# silhouette; a step that runs edge to edge saws the body into stripes.
# The binding is two unlit slots in the left margin, not a drawn spine: a spine
# at this width eats the page it is supposed to be holding.

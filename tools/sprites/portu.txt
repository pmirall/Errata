# Family 17 - PORT. Family motif: a rectangular SLAB stood on the floor,
# pierced by DOORWAYS - unlit rectangles that reach the bottom edge, so the
# background shows through and the gaps between them are the creature's legs.
# All three stages are the same slab: one door, then three, then a wall so
# perforated that one doorway has torn its own frame open.
# Eyes are unlit 2x2 holes ABOVE the doorways, so the doorway reads as a mouth
# and the slab reads as a face rather than as masonry.
#
# PORTU - species 49, family 17 stage 0, type SYSTEM (PORT / TANK).
# 'A polite little door.'
# root:       slab with a rectangular THROUGH-hole
# silhouette: 12x9 slab, one 4x3 through-hole, two dot eyes above it.
# frame 2:    a shutter closes the hole to 1px and opens it.
#
# The doorway is cut DOWN TO THE FLOOR rather than left as a window: an
# enclosed hole in a 12x9 body is four unlit pixels wide with lit pixels all
# round it, which at 1x is a smudge. Open at the bottom it breaks the
# silhouette, so it reads as a doorway and leaves the baby two stubby legs.
# The shutter therefore closes DOWNWARD and stops 1px short of the floor -
# the outline never changes, only the hole inside it, which is what keeps a
# 420 ms two-frame alternation reading as a door and not as a flicker.

#
# P9-C3 INTEGRATION FIX: THIS BODY WAS EXACTLY SYMMETRIC ABOUT ITS OWN CENTRE
# COLUMN, so ui/xbm_mirror.cpp produced a byte-identical picture and the two
# fighters on the battle field faced the same way.  Nothing in the pipeline can
# see that - the mirror still ran, the ink count is the same, the bounding box
# is the same - and it was found by a test that renders the upright and the
# mirrored body and requires them to differ (tests/test_screens.cpp,
# every_species_draws_on_the_battle_field_without_clipping).  Spec 18/19 wants
# asymmetry anyway; this is the smallest edit that gives the body a facing.
# PORTU: the left eye hole is now 3px and the right 2px, so the face is
# lopsided and the middle pillar sits off centre.

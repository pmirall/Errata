# Family 20 - COOKIE. Family motif: an EYE ON A STALK. The body is a stalk,
# never legs and never a torso; everything else is eyes budded off it, and
# every stage adds eyes rather than bulk. The stalk stands on a small pad, and
# by the last stage the pad has come apart into loose dots.
# An eye here is always the same three rings: a 2px lit rim, an unlit sclera
# inside it, and a LIT pupil inside that. The pupil is what moves - it is the
# only moving part in all three stages, and it is why the family reads as
# watching rather than as breathing.
#
# PANOPTIX - species 60, family 20 stage 2, type SYSTEM (COOKIE / FAST).
# 'It sees everything, always.'
# root:       eye on a stalk - tall and thin, never legs
# silhouette: one 18px stalk with nine eyes on short branches filling the
#             frame, the base dissolved into dots.
# frame 2:    the pupils sweep in a wave from base to tip.
#
# Sections 18/19 want the final stage bigger and more asymmetric: this one is
# 18 wide and fills all 24 rows, the eight side eyes alternate left and right
# at two-row offsets so no two are level, and the base is not a pad any more -
# it has come apart into loose dots, which is the only silhouette in these
# twelve that does not stand on anything.
# The crown eye is the family's three-ring eye, the same one Cookit is built
# from. The eight buds are not: at 5x3 the ring encoding collapses into
# alternating single pixels, so a bud is a solid lit block with one UNLIT
# pupil in it. Rendered side by side, that is the honest trade - nine eyes
# that read as eyes, at the cost of the small ones inverting the big one.
# The wave is one pupil-step per eye, taken in base-to-tip order, so between
# the two frames every one of the nine pupils moves 1px the same way round: 22
# px, which is a ripple. Moving them all to the same column instead would be
# 9 eyes blinking in unison, which at this size is just a flicker in the
# middle of the tower.

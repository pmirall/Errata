# Family 13 MEMORY motif: a SOLID VERTICAL SLAB with a comb of contact notches
# bitten out of its bottom edge, a 1px waist notched into both side walls, and
# one 2x2 unlit eye per slab. Growth is by slab count - one, two, three - and
# the bottom edge decays across the three stages: clean comb, clean comb,
# then a melt. Eyes are unlit holes, never lit dots: the body is a solid
# silhouette, so a lit eye inside it is invisible.
#
# LEKRON - species 39, family 13 stage 2, type SYSTEM (MEMORY / BRUISER).
# 'Pide mas y nunca suelta.' - it asks for more and never lets go: the leak.
# root:       vertical notched stick melting DOWNWARD
# silhouette: three fused sticks, the bottom third melted into five drips of
#             unequal length.
# frame 2:    the longest drip detaches into a falling 2px bead.
# Three slabs, tops at three different heights and the middle one drawn up to a
# horn at row 0, so the outline is asymmetric and sharp at the top the way
# sections 18-19 ask a final stage to be. The slabs are separate above row 12
# and fused solid below it. The comb is gone: the contact teeth have run into
# five drips, which is what the bottom edge of this family decays into.
# Three eyes at three heights - one per slab - keep it the same creature.
# frame 1 shortens drip 2 by three rows and puts a 2x2 bead below the gap; the
# rightmost drip grows 1px at the same time so the melt reads as ongoing.

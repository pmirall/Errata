# Family 17 - PORT. Family motif: a rectangular SLAB stood on the floor,
# pierced by DOORWAYS - unlit rectangles that reach the bottom edge, so the
# background shows through and the gaps between them are the creature's legs.
# All three stages are the same slab: one door, then three, then a wall so
# perforated that one doorway has torn its own frame open.
# Eyes are unlit 2x2 holes ABOVE the doorways, so the doorway reads as a mouth
# and the slab reads as a face rather than as masonry.
#
# SKANOR - species 50, family 17 stage 1, type SYSTEM (PORT / TANK).
# 'It tries every door.'
# root:       slab with a rectangular THROUGH-hole
# silhouette: 16x11 slab, three through-holes in a row, a 2px probe bar
#             sliding across them.
# frame 2:    the probe bar moves one hole to the right.
#
# The probe is drawn OUTSIDE the slab, hovering one row clear of it. Inside
# a doorway it would be lit-on-lit against the slab it is probing and would
# read as a pillar; above it, on unlit background, it is the only thing in
# the frame that moves and the move is a silhouette change, which is what a
# 1x panel can actually resolve. The head is 4px wide over a 3px doorway so
# it visibly points at the door it is trying.
# The slab is 17px wide, not the brief's 16, because 3 doorways + 2 pillars
# + 2 margins only divides evenly at 17; at 16 one leg comes out 1px wide.

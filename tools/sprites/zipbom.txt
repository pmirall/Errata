# Family 14 FILE motif: a SOLID PAGE whose top-right corner is cut away on the
# diagonal, with a 1px unlit CREASE running parallel to that cut, two dot eyes
# and a short mouth low on the page. The crease is stopped one step short at
# both ends so the folded flap stays ATTACHED to the page - a crease that runs
# edge to edge cuts the flap off the silhouette and it reads as a loose bar.
# Growth is by page count: one page, three fanned pages, then a page that has
# unrolled into a burst of page corners big enough to leave the frame.
#
# ZIPBOM - species 42, family 14 stage 2, type SYSTEM (FILE / BALANCED).
# 'Se abre y ya no cabe.' - it opens and then it does not fit any more.
# root:       folded-corner sheet (the only folded plane)
# silhouette: one sheet whose fold has unrolled into a spiral of eleven nested
#             sheets bursting from the corner, outer ones clipped by the frame.
# frame 2:    the spiral unwinds one turn: a new sheet appears at the corner,
#             the outermost leaves the frame.
# FOUR nested corners, not eleven. Eleven inside 24px is a 2px pitch, and 2px
# pitch of 1px lines is a grey field that flickers on a 1-bit panel - the same
# reason this phase forbids dither. Four corners at a 4px pitch, 2px thick,
# each chamfered so it reads as a folded page corner and not as a bracket, is
# what the panel can actually show. The outermost is clipped by the top edge.
# The face stays on the source sheet at bottom left so the burst has a creature
# under it; the 1px diagonal spine ties every corner back to that sheet, so the
# silhouette is connected rather than a page and some floating furniture.

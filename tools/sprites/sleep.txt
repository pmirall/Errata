# SLEEP - THE ONE SLEEPING BODY, drawn at P9-C3.
#
# The legacy atlas had four (SLEEP_BABY/CHILD/TEEN/ADULT at 24, 28, 32 and 40
# px), and sprite_set_id() ignored `form` in the pose branches, so a sleeping
# Paketo, Buggo, Nulix and Murax were ALREADY the same blob.  The identity loss
# is inherited, not introduced: what changes is that there is one of these
# instead of four, and it is 24x24 like every body it replaces.
#
# It is deliberately generic - a settled lump with its eyes shut - because it
# stands in for sixty creatures.  Shut eyes are SLITS, not filled sockets: on a
# 1-bit panel an unlit slit inside a lit mass is the only shape that reads as a
# closed eye at 24px.  ui.cpp already floats EMO_ZZZ beside a sleeping pet, so
# this body does not draw one.
#
# Frame 1 is a breath: the dome rises one row and the mouth opens one pixel each
# way.  14 px of change, which is the quietest idle in the atlas, and correct -
# a sleeping animal that twitches is not asleep.
